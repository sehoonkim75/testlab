# testlab

자기소개서 검토, 면접질문 생성, 자기소개서 불성실(대필·복붙 등) 탐지를 위한 실험용 도구 모음입니다. 브라우저에서 바로 여는 HTML 도구와, 대량 데이터를 배치로 처리하는 Jupyter 노트북으로 구성되어 있습니다.

> ⚠️ 모든 도구는 OpenAI API를 사용합니다. 실행/사용 전에 OpenAI API 키가 필요하며, 입력한 자기소개서 원문이 OpenAI 서버로 전송된다는 점을 반드시 인지하고 사용하세요. (자세한 내용은 [공통 유의사항](#공통-유의사항) 참고)

## 페이지/파일 구성

### 1. 면접질문 생성기 (HTML)

자기소개서와 모집분야 직무수행내용을 분석해 평가요소별 맞춤형 면접질문(주질문·근거구절·질문이유·보조질문)을 생성하는 도구입니다. 서버 없이 브라우저에서만 동작하며, 단건 테스트로 프롬프트를 튜닝한 뒤 엑셀 일괄 처리로 대량 생성 및 결과 다운로드가 가능합니다.

| 파일 | 설명 |
| --- | --- |
| [`면접질문생성기.html`](./면접질문생성기.html) | 최초 버전 |
| [`면접질문생성기v2.html`](./면접질문생성기v2.html) | 개선 버전 |
| [`면접질문생성기v3.html`](./면접질문생성기v3.html) | 최신 버전. 자기소개서 항목별 요약, 문항별 작성 분량 확인 기능 추가 |

기본 사용 순서: **API 키 등록 → (필요 시) 시스템 프롬프트 편집·적용 → 단건 테스트 탭에서 프롬프트 튜닝 → 엑셀 일괄 처리 탭에서 대량 생성 → 결과 엑셀 다운로드**

### 2. 자기소개서 불성실 탐지 서비스 (HTML)

자기소개서 문항을 분석해 대필, 문항 재활용, 복붙 등 불성실 작성 여부를 탐지하고 종합판정(정상/경미/주의 등)을 내려주는 도구입니다. 탐지 조건을 직접 설정하고 결과를 확인할 수 있습니다.

| 파일 | 설명 |
| --- | --- |
| [`자기소개서_불성실탐지_서비스_v3.html`](./자기소개서_불성실탐지_서비스_v3.html) | v3. API 키를 화면에서 직접 입력해서 사용 |
| [`자기소개서_불성실탐지_서비스_v4(배포용).html`](./자기소개서_불성실탐지_서비스_v4(배포용).html) | v4(배포용). v3 기능에 더해 탐지된 지원자별 개별 리포트(HTML)를 ZIP으로 일괄 다운로드하는 기능 추가. 배포 시 API 키를 코드 내에 미리 심어 배포하는 용도 |

기본 사용 순서: **분석 설정 → 탐지 조건 설정 → 자기소개서 입력(단건 또는 엑셀 업로드) → 불성실 탐지 시작 → 탐지 결과 확인 및 엑셀/개별 리포트(ZIP) 다운로드**

### 4. Jupyter 노트북 (Python)

엑셀 등 대량 데이터를 배치로 처리할 때 사용하는 파이썬 스크립트입니다. OpenAI API(`openai` 패키지)와 `openpyxl`, `pandas`를 사용합니다.

| 파일 | 설명 |
| --- | --- |
| [`1. 자소서기반 질문생성.ipynb`](<./1. 자소서기반 질문생성.ipynb>) | 자기소개서 엑셀을 입력받아 지원자별 면접질문(주질문/근거구절/질문이유/보조질문)을 대량 생성해 엑셀로 저장 |
| [`2. 리포트생성 최신.ipynb`](<./2. 리포트생성 최신.ipynb>) | 위 단계에서 생성된 자기소개서 원본 엑셀 + 면접질문 결과 엑셀을 입력받아, 지원자별 개별 면접 리포트를 HTML로 생성 |
| [`자기소개서 불성실탐지.ipynb`](<./자기소개서 불성실탐지.ipynb>) | 자기소개서 엑셀을 입력받아 문항별 불성실 여부를 판정하고 결과를 엑셀로 저장. 위 "이용 가이드" HTML 문서와 함께 사용 |

권장 파이프라인(면접질문/리포트 생성 시): `1. 자소서기반 질문생성.ipynb` 실행 → 결과 엑셀을 입력으로 `2. 리포트생성 최신.ipynb` 실행 → 지원자별 HTML 리포트 확인

## 공통 유의사항

- **API 키 보안**: HTML 도구는 입력한 API 키를 해당 브라우저 탭에만 보관하며, 탭을 닫으면 삭제됩니다. 공용 PC에서는 사용 후 반드시 탭을 닫으세요. 노트북은 환경변수 또는 코드 내 키 입력 방식을 사용하므로 키를 커밋하거나 공유하지 않도록 주의하세요.
- **비용 발생**: 생성/탐지 1건마다 OpenAI API 사용 요금이 부과됩니다. 대량 처리 전 단건 테스트로 결과 품질과 비용을 먼저 확인하세요.
- **개인정보 취급**: 자기소개서 원문이 OpenAI 서버로 전송됩니다. 소속 기관의 개인정보 처리 방침과 외부 API 이용 규정을 준수하는 범위에서 사용하세요.
- **AI 생성물 검토**: 생성된 질문/판정 결과는 초안(참고용)입니다. 실제 활용 전 사람이 반드시 검토하세요.

## 참고

- HTML 도구는 별도 설치 없이 파일을 브라우저에서 열기만 하면 실행됩니다.
- 노트북 실행에는 Python 환경과 `openai`, `openpyxl`, `pandas` 패키지가 필요합니다 (`pip install openai openpyxl pandas`).
