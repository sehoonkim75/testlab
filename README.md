# 채용 서류·면접 AI 지원 도구 모음

공공기관 채용 담당자가 **자기소개서를 검토하고 면접을 준비하는 일**을 돕는 도구 모음입니다.
설치 없이 브라우저에서 바로 여는 **웹 도구 2종**으로 이루어져 있으며, 한 명씩 입력하는 방식과 엑셀로 여러 명을 한꺼번에 처리하는 방식을 모두 지원합니다.

| 해결하려는 문제 | 도구 | 결과물 |
| --- | --- | --- |
| 수백 건의 자기소개서에서 블라인드 채용 위배·불성실 작성을 사람이 일일이 찾아야 함 | [자기소개서 불성실 탐지 서비스](#1-자기소개서-불성실-탐지-서비스) | 지원자별 정상·경미·주의 판정과 근거 구절, 서식이 들어간 엑셀, 개별 보고서 |
| 지원자마다 자기소개서에 근거한 면접질문을 만드는 데 시간이 오래 걸림 | [자기소개서 기반 면접질문 생성기](#2-자기소개서-기반-면접질문-생성기) | 평가요소별 주질문·근거 구절·질문 의도·보조질문, 개별 면접 보고서 |

> ⚠️ 모든 도구는 OpenAI API를 사용합니다. 입력한 자기소개서 원문이 OpenAI로 전송되며 사용량만큼 요금이 발생합니다. 자세한 내용은 [보안·개인정보 유의사항](#보안개인정보-유의사항)을 확인하세요.

## 공통 설계 원칙

두 웹 도구는 같은 디자인 체계와 화면 흐름을 씁니다.

- **4단계 마법사** — `1 시작하기 → 2 설정 → 3 자기소개서 입력 → 4 결과 확인`. 위쪽에 고정된 진행 표시줄로 지금 어디에 있는지 늘 보입니다.
- **한 화면에 설정 2개 이하** — 설정은 짧은 세부 화면으로 나눴습니다. 각 화면은 추천값으로 미리 채워져 있고, 처음 쓰는 사람은 **추천 설정으로 건너뛰기**로 바로 입력 단계에 갈 수 있습니다.
- **즉시 피드백** — 빠른 선택(프리셋), 판정 범위 미리 보기 막대, 입력 칸 아래 바로 뜨는 오류 안내, 마지막 화면의 설정 요약과 [수정] 바로가기.
- **다시 설정하지 않아도 되게** — 설정은 브라우저에 저장되어 다음에 열 때 그대로 불러옵니다. 화면별·전체 초기화 단추도 있습니다.
- **실패해도 이어서** — 요청 제한(429)·서버 오류는 자동으로 다시 시도하고, 키·모델 오류는 바로 멈춰 알려 줍니다. 일괄 처리 중 중단, 남은 시간 표시, 실패한 건만 다시 시도할 수 있습니다.
- **접근성·반응형** — 글자 대비 4.5:1 이상, 버튼·입력칸 경계 대비 3:1 이상, 휴대폰에서 누르는 영역 44px 이상, 키보드 초점 표시, `aria` 속성, 휴대폰 너비(390px)에서도 가로 넘침 없는 배치.
- **보이는 곳에 안내** — 입력 오류와 경고는 문제가 생긴 칸 바로 아래에 닫을 때까지 남고, 잠깐 떴다 사라지는 알림은 '복사했습니다' 같은 완료 안내에만 씁니다. 비활성 단추에는 쓸 수 없는 이유를 함께 보여 줍니다.
- **정돈된 시각 체계** — 글자 크기를 13·15·16·17·20·24px 여섯 단계로 통일하고, 빨강·노랑·초록은 판정(주의·경미·정상)에만 씁니다.
- **설치 없음** — HTML 파일 하나로 동작합니다. 엑셀·압축 기능만 CDN 라이브러리(SheetJS·ExcelJS·JSZip)를 불러옵니다.

## 1. 자기소개서 불성실 탐지 서비스

📄 [`자기소개서_불성실탐지_서비스.html`](./자기소개서_불성실탐지_서비스.html)

자기소개서의 **블라인드 채용 위배**와 **불성실 기입**을 찾아 문항별·지원자별로 `정상 / 경미 / 주의`를 판정합니다.

### 탐지 항목

| 묶음 | 항목 | 판정 방식 |
| --- | --- | --- |
| 😐 불성실 기입 | 글자 수 부족 · 항목 간 복사·붙여넣기 의심 · 답변 공란 | ⚙️ 규칙 판정 |
| | 의미 없는 반복 · 다른 기관명 기재 · 기타 불성실 기입 | 🤖 인공지능 판정 |
| 🚫 블라인드 위배 | 출신 지역 · 가족관계 · 성별 · 출신 학교 · 나이 · 기타(추가 탐지 단어) | ⚙️+🤖 병행 판정 |
| | 성명 · 혼인 및 출산 · 종교 | 🤖 인공지능 판정 |
| 📌 기타 | 직무와 무관한 내용 (+ 기관이 직접 추가한 항목) | 🤖 인공지능 판정 |

블라인드 위배가 하나라도 나오면 정도와 상관없이 종합 판정을 `주의`로 올립니다.

### 화면 흐름

1. **시작하기** — 서비스 소개, 유의사항, 인공지능 모델 고르기(카드)
2. **탐지 조건 설정** — 7개의 짧은 화면
   `글자 수 기준 → 복사·붙여넣기 기준 → 기관명·추가 탐지 단어 → 불성실 항목 → 블라인드 항목 → 기타 항목 → 설정 확인`
   (판정 지시문 직접 수정은 마지막 화면의 '고급' 메뉴로 옮김)
3. **자기소개서 입력** — 직접 입력(답변 아래 글자 수 판정을 바로 표시, 예시 답변 넣기) 또는 엑셀 업로드(미리 보기, 예상 소요 시간)
4. **결과 확인** — 판정별 집계, 걸러 보기·검색, 근거 구절을 색으로 표시한 답변 원문, 서식이 들어간 엑셀, 지원자별 보고서 압축 파일

### 기술 포인트

- **규칙 + 인공지능 혼합 판정** — 정답이 분명한 항목은 코드가 판정해 결과가 늘 같고, 문맥 판단이 필요한 항목만 모델에 맡깁니다.
- **항목 간 유사도** — 공백·문장부호를 뺀 뒤 두 글자 단위(bigram) **다이스 계수**로 복사·붙여넣기 여부를 계산합니다.
- **블라인드 정규식 탐지** — 학교명·지역·성별·나이·가족 직업 패턴을 먼저 찾아 인공지능 판정과 합칩니다.
- **구조화 출력** — `response_format: json_schema`(strict)로 응답 형식을 강제하고, 응답은 순서가 아니라 문항 번호로 연결합니다.
- **근거 검증** — 모델이 낸 근거 구절은 원문에 실제로 있을 때만 채택해, 없는 문장을 지어내는 것(환각)을 막습니다.
- **판정 지시문 자동 생성** — 화면에서 고친 판정 기준·탐지 사례·제외 사례가 그대로 지시문에 들어갑니다.
- **병렬 처리** — 일괄 탐지는 최대 3명씩 동시에 처리하고, 남은 시간을 실시간으로 보여 줍니다.

> 이 파일은 **내부 시험용**으로, 파일 안의 `EMBEDDED_API_KEY`에 키를 넣어 쓰는 구조입니다. 저장소에는 빈 값으로 올라가 있으며, 키를 넣은 파일은 공개 저장소나 공개 주소에 올리지 마세요. 키가 없어도 규칙 판정 항목만 켜면 외부 전송 없이 분석할 수 있습니다.

## 2. 자기소개서 기반 면접질문 생성기

📄 [`면접질문생성기.html`](./면접질문생성기.html)

자기소개서와 모집 분야의 직무수행내용을 분석해 **평가요소별 맞춤 면접질문**을 만듭니다.
질문마다 `주질문 · 자기소개서 근거 구절 · 질문 의도 · 보조질문(STAR 후속 질문)`이 붙고, 문항별 요약과 작성 분량도 함께 정리됩니다.

### 화면 흐름

1. **시작하기** — 유의사항 동의, 오픈에이아이 접속 키 등록(탭을 닫으면 지워짐)
2. **생성 설정** — 4개의 짧은 화면
   `모델·질문 다양성 → 보고서 로고 → 평가요소·보조질문 수 → 설정 확인`
3. **자기소개서 입력** — 직접 입력(제한 글자 수 대비 작성 분량 막대, 예시 자기소개서 넣기) 또는 엑셀 업로드(지원자 골라서 생성, 직무내용 연결 여부 표시, 예상 소요 시간)
4. **결과 확인** — 지원자별 보고서, 질문 하나씩·전체 복사, 인쇄·PDF 저장, 실패한 지원자만 다시 시도, 엑셀·보고서 압축 파일 내려받기

### 기술 포인트

- **지시문 자동 생성** — 평가요소(빠른 선택: 공공기관 5요소 / 직업기초능력 / 역량 중심, 직접 입력은 최대 8개)와 보조질문 수(1~5개)로 시스템 지시문과 응답 JSON 예시를 만듭니다. 고급 사용자는 지시문을 직접 고쳐 확정할 수 있고, 질문 구성을 바꾸면 확정이 자동으로 풀려 예전 구성으로 생성되는 일을 막습니다.
- **엑셀 2시트 연결** — "자기소개서" 시트(수험번호 기준 묶음)와 "직무내용" 시트(모집 분야 기준)를 이어 붙여 직무 연관 질문을 만듭니다.
- **보고서** — 기관 로고, 블라인드 처리한 이름, 문항별 요약표, 작성 분량 막대, 원문을 담은 독립 HTML 파일로 저장하며, A4 인쇄용 스타일을 따로 둡니다.

### 엑셀 입력 형식

| 시트 | 열 구성 |
| --- | --- |
| 자기소개서 | 수험번호 · 이름 · 모집분야 · 전형단계 · 질문 · 답변 · 제한글자수 |
| 직무내용 (선택) | 모집분야 · 직무수행내용 |

화면의 **입력 양식 내려받기**로 예시가 들어 있는 양식을 받을 수 있습니다.

## 기술 스택

- **웹**: HTML · CSS(뉴모피즘 디자인 토큰, 반응형) · 순수 자바스크립트(프레임워크 없음)
- **라이브러리**: SheetJS(엑셀 읽기·쓰기) · ExcelJS(서식이 들어간 엑셀) · JSZip(보고서 압축)
- **AI**: OpenAI Chat Completions API (JSON 구조화 출력)

## 보안·개인정보 유의사항

- **API 키** — 면접질문 생성기는 키를 브라우저 탭에만 보관하고 탭을 닫으면 지웁니다. 불성실 탐지 서비스는 파일 안에 키를 넣는 내부 시험용 구조이므로, 키를 넣은 파일은 외부에 공유하지 말고 OpenAI 관리 화면에서 사용 한도를 정해 두세요. 키가 들어 있는 파일은 저장소에 커밋하지 마세요.
- **개인정보** — 자기소개서 원문이 OpenAI로 전송됩니다. 기관의 개인정보 처리 방침과 외부 서비스 이용 규정 안에서 사용하세요. 보고서의 지원자 이름은 자동으로 블라인드 처리됩니다.
- **비용** — 처리 1건마다 요금이 발생합니다. 대량 처리 전에 한 명으로 먼저 시험하세요.
- **결과 검토** — 판정과 질문은 참고용 초안입니다. 실제 활용 전에 반드시 담당자가 검토하세요.
